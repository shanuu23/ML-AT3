# ML-AT3 Group Project

This repository is for the code, notebooks, datasets, and modelling outputs for the 36106 Machine Learning AT3 group assignment.

The written report is being managed separately in the team Docs file.

## Assignment Brief

A global retailer has collected transactional customer data over several years. The business wants the data science team to explore the available datasets and propose machine learning use cases that can create value for the business or its customers.

Each group member will define one business use case, map it to a data mining task, perform EDA, train relevant machine learning models, evaluate the results, and share outputs needed for the final group report.

Across the group, the project must cover these four data mining tasks:

- Classification
- Regression
- Anomaly detection
- Clustering
